# Brand — Aerisk

Single source of truth for how the company is named and presented. Update here
first; other files reference this.

## Name

- **Legal/brand name:** Aerisk
- **Origin:** *Aero* + *Risk* — drone/UAS risk & safety engineering in one word.
- **Pronunciation:** "AIR-isk".
- **Usage:** Always capitalized "Aerisk" (not "AeRisk", "AERISK", or "aerisk"
  outside of domains/handles). Never add a generic suffix in prose ("Aerisk",
  not "Aerisk Consulting") unless legal form requires it.

## Domain & handles

- **Primary domain:** `aerisk.aero` (the aviation-sponsored TLD — signals
  aviation-native; preferred over `.com`, which is parked by an unrelated party).
- **Available fallbacks (verified free at selection):** `aerisk.io`,
  `aerisk.co`, `aerisk.net`, `aerisk.eu`.
- **Email convention:** `firstname@aerisk.aero` (set once domain is registered).

## Logo / wordmark

- **Current state:** text wordmark only — a visual logo is deferred.
- **Wordmark:** the word **Aerisk** set in a clean, geometric sans-serif.
- When a visual mark is commissioned, drop the asset under `assets/` and point
  `IDENTITY.md` (`Avatar`) and this file at it.

## Selection notes (2026-06-27)

Chosen over: *Tutela Aerospace* (clean but more corporate), *Aerassure*
(generic). Rejected for shadow risk: *Skora* (crowded trademark), *Caelum*
(three drone firms incl. UK Project CAELUS), *Volans* (≈ Volansi drone-delivery).

*Rexar* (cross-checked 2026-06-27): rejected — `rexar.com` held since 1999
(MarkMonitor, locked), 3+ active exact-name firms (rexar.io offensive security,
rexar.net cloud, rexar.nl EU lab supplies), pharma baggage (Rexar Pharmacal →
Adderall), and no semantic tie to drones/risk. Kept on the bench for a possible
future rebrand only if those clear.
