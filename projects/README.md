# Projects / Engagements

One folder per client engagement. **Do not** work directly in `_TEMPLATE/` —
copy it.

## Naming convention

```
projects/<YYYY>-<client>-<short-name>/
```

Examples:
- `projects/2026-acme-bvlos-sora/`
- `projects/2026-cityworks-bridge-inspection-risk/`

## Starting a new engagement

1. Copy `_TEMPLATE/` to a new folder following the convention above.
2. Fill in `00-engagement.md`.
3. Populate inputs in `01-inputs/`, work in `02-working/`, deliverables in
   `03-deliverables/`.
4. Tag the issued deliverable in git (e.g. `v1.0-acme-report`).
