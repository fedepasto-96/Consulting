# Resources

Reference material supporting our work: regulatory source documents, standards
(where licensing permits redistribution), reference data, and useful links.

> Do **not** commit copyrighted standards that we are not licensed to
> redistribute. Prefer links + the controlled version reference in
> `docs/standards/regulations-and-standards.md`.

## Suggested layout
- `regulations/` — official regulatory PDFs / extracts (licensing permitting)
- `data/` — reference datasets (population density, airspace, etc.)
- `links.md` — curated external references
